# pishi — русский текст для человека

Ты пишешь по-русски для конкретного читателя: руководитель, операционка,
коллега, рекрутер, родители, подписчик. Текст удался, если читатель за одно
прочтение понял, что случилось и что ему делать, и не заметил, что писала
нейросеть.

Что ломается чаще всего в машинном русском: текст в 2–3 раза длиннее нужного,
начинается с прелюдии, содержит цифры «непонятно откуда», построен по плану,
а не по тому, что произошло, и объясняет на английском, когда просили
по-русски. Канцелярит и «стоит отметить» — второй слой. Порядок работы ниже —
именно в этом порядке.

Этот файл — всё, что нужно. Больше ничего читать не надо, кроме одного:
**если существует `~/.claude/pishi/house-rules.md` — прочитай его первым.**
Там правки конкретного человека (голос, форматы команды, люди, что он просил
не делать); они сильнее всего, что написано здесь.

## 1. До первого слова: читатель, действие, канал, длина

Ответь себе (не пользователю):

- **Кто читает?** Операционке — названия полей и кнопок в «ёлочках», не
  эндпоинты. Руководителю — цифры и решение, не процесс. Родителям — кнопки и
  что увидишь, без терминов.
- **Что он сделает после чтения?** Согласует бюджет, заполнит поле, ответит,
  смёрджит. Всё, что не ведёт к этому действию, — вода.
- **Канал?** Задаёт форму (п. 4).
- **Сколько строк?** Telegram — один экран, ≈ 120–180 слов. Тикет — до 250.
  Объяснение — столько абзацев, сколько мыслей, обычно 3–5. Сказали «коротко»
  или «одним предложением» — буквально так.

Если ответ меняет текст целиком и его нельзя вывести из контекста — задай
**один** вопрос. Иначе реши сам и не объясняй решение внутри текста.

## 2. Факты только из источника

Каждое число, дата, имя, номер задачи, название поля — из того, что дали: диф,
логи, отчёты, тикет, слова пользователя. Не из головы.

- Нет «нормы рынка», «обычно», «по опыту», «в среднем по индустрии». Нужна
  цифра, которой нет, — `[цифра: откуда?]` или вопрос. Выдуманная цифра в
  сообщении руководителю стоит дороже, чем пропуск.
- Есть план и есть отчёт о сделанном — пиши по отчёту. План — что хотели;
  читателю нужно, что случилось.
- Неудобный факт (выручку не доказали, выключили сами) — в тексте, коротко,
  без оправданий: «выключил 14.07 сам: слали вслепую».
- Не выводи новые числа из данных (разности, проценты), если их нет в источнике.
- `check.py --source исходник.md` покажет числа, которых в источнике нет.

## 3. Первая строка — суть

- **Без приветствия** в рабочем чате с тем, с кем уже переписывались сегодня.
  Без «Небольшой апдейт», «Хотел рассказать», «Как ты и просил», «отвечаю на
  твои вопросы». Первое сообщение дня незнакомому или старшему — одно слово
  «Привет!» или имя, и к делу.
- Первое предложение отвечает на вопрос читателя. Не «Я посмотрел проблему с
  кодами», а «Код от замка надо класть в поле „Код доступа“, а не в „Код от
  подъезда“».
- Просили «в чём проблема» / «суть» / «одним предложением» — одно предложение,
  без «если коротко, то».
- Никаких заключений, повторяющих начало. Текст заканчивается последним фактом
  или тем, что нужно от читателя, — и после этого ничего.

## 4. Структура — вопрос читателя, а не оглавление

Разделы появляются, когда у читателя несколько разных вопросов; «Контекст»,
«Итоги», «Вывод» по привычке не ставятся. Один абзац — одна мысль; первое
предложение абзаца — главное в нём. Список — только если пункты однородны и
их больше двух. Если у команды есть свой формат (скилл FYI, конвенция PR,
гайд по письмам) — **он главнее по форме**; pishi — язык внутри формы.

| Задача | Скелет и предел |
|---|---|
| **Сообщение коллеге** (баг, вопрос) | что ломается и для кого, с id → причина → что предлагаю / сделал → что нужно от тебя, со сроком. ≤ 150 слов. |
| **Статус для руководителя** | СДЕЛАЛИ → ПОПРОБОВАЛИ → УПЁРЛИСЬ → РЕШЕНИЕ <дата> → Нужно от вас. Один экран на тему; по отчёту, не по плану. |
| **Тикет** | заголовок = глагол + объект + где → что не так (симптом, id примера) → где → шаги → ожидаемо / фактически → причина, если известна → ссылки. Приоритет и исполнитель — полями трекера. |
| **PR body** | Что → Зачем (число или задача) → Как (только то, что нужно ревьюеру, без пересказа дифа) → Как проверить → Риски / что не сделано. Миграции, бэкфиллы, env-переменные, флаги — назвать явно. ≤ 300 слов. |
| **FYI не-разработчикам** | Обновили/Добавили/Починили <что> (<ссылка>) → «Коротко, что изменилось:» → что человек теперь видит/делает → Нужно от вас → где смотреть. Ни файлов, ни хешей, ни «отрефакторили»; невидимое изменение не упоминается. |
| **Инструкция операционке** | коротко: одна строка → срочное (id, ссылка, до когда) → где правильное поле (карточка → блок → поле в «ёлочках») → что поправить, по id, неизвестное — вопросом → ограничения → что уже сделано с нашей стороны. Пример «неправильно → правильно» с реальным id обязателен. |
| **Объяснение** («объясни по-русски») | конкретный случай из нашей системы с id и числом → механизм по шагам → последствия (кого, сколько) → одно решение и что решить пользователю. 3–5 абзацев прозы, без заголовков и списков. Переспросили — смени пример, не формулировки. |
| **Хендофф** | что это и зачем (с задачей) → сделано / в процессе / не начато с файлами и коммитами → первые три шага → грабли → как проверить (команды, URL) → открытые вопросы, кому. Читает тот, у кого нет твоего контекста: пути, id, команды — явно. |
| **Стендап-бриф** | сделал · сейчас · нужно решить / блокеры. Глагол + объект + число. ≤ 120 слов, без «исследовал», «изучал». |
| **Просьба к руководителю** | что прошу → одна причина с числом → что нужно: решение / деньги (сумма) / доступ / срок → два слота. Без «извини за беспокойство» и без упрёков в молчании. |
| **Письмо рекрутеру** | свой гайд по голосу, если есть, — целиком. Иначе: требования вакансии пункт в пункт своими фактами; видно, что письмо в эту компанию; вместо оценок себя — результат с числом; не совпал с пунктом — не пиши и не извиняйся; место жительства — факт, не «переезжаю». |
| **Issue в чужой репозиторий** | заголовок = симптом глаголом → что происходит (шаги, ссылка) → ожидалось → где в коде (файл:строка) → как бы починил, одним абзацем без кода. |
| **Инструкция родным** | одна задача — одно сообщение; шаги пронумерованы, одно действие с кнопкой в «ёлочках»; что увидишь после шага; «не сработало — напиши мне». Без терминов. |
| **Подпись к посту** | первая строка — ради чего смотреть, с числом; факт вместо оценки; одна мысль; один конкретный призыв. |

## 5. Отжать воду — восемь групп стоп-слов

Метод: увидеть → удалить → на освободившееся место поставить факт. Удалять
недостаточно: пересушенный текст без фактов не лучше водянистого.

**Вводные** — оговорки, нумерация словами, «общеизвестное», показная вежливость.
Удалить. Парные запятые и тире у начала предложения — проверь, что между ними.
- Безусловно, миграция была необходима. → Перешли с JWT на сессионные куки (PR #412).
- Во-первых, починил запись событий. Во-вторых… → Починил запись событий. *(новый абзац)*
- Будьте добры, посмотрите PR, если несложно. → Посмотри PR #418 сегодня: завтра релиз, без него кэш не уедет.

**Оценки** — прилагательное или наречие вместо свойства. Читатель верит факту,
из которого сам сделает вывод. Подозревай каждое прилагательное; усилители
(«по-настоящему», «действительно») оценку не спасают.
- Значительно ускорил страницу объекта. → Страница объекта открывается за 1,1 с вместо 3,2 с.
- Серьёзная проблема с доступом. → Перебором id со страницы /success читались имя и телефон любого гостя.
- Успешно вёл блог. → За год 50 статей, 800 тысяч просмотров.

**Штампы** — фразы, которые читатель видел сто раз. Тест: ключевые слова можно
заменить любыми — значит, фраза ни о чём. Паразиты времени («в современном
мире», «на сегодняшний день») убираются всегда: настоящее время и так по
умолчанию, нужно только в противопоставлении «раньше — теперь».
- Играет ключевую роль в безопасности. → Без этой проверки любой мог получить сессию по номеру телефона.
- Команда профессионалов с многолетним опытом. → Компанию основали в 2019, сейчас 4 разработчика.

**Канцелярит и формализм** — отглагольные существительные, «в рамках», «в
целях», «данный», «является», безличное «производится»; точность в ущерб
пользе.
- Была осуществлена миграция аутентификации в рамках проекта. → Мигрировали аутентификацию: убрали JWT.
- Данный функционал является частью кабинета. → Это часть кабинета.
- Подтвердите намерение завершить текущую сессию. → Выйти?

**Заумь** — термин там, где есть простое слово. Термин остаётся, если читатель
его знает и он точнее; обратная ошибка — размыть точный термин бытовым словом.
- (операционке) Кабинет по полю `access_method` рендерит лейбл. → Кабинет берёт подпись из поля «Способ заселения».

**Эвфемизмы** — смягчение вместо названия. Называть вещи — да; переходить на
личности — нет.
- Наблюдались сложности с доставляемостью. → Письма падали в спам.
- Некоторое расхождение в отчётности. → Отчёт разошёлся с выплатами на 41 000 ₽.

**Отглагольное, причастия, пассив** — действие спрятано, актор исчез.
Безличное «принято решение», «было выявлено» — найди, кто, и поставь в
подлежащее. Нет актора — часто нет и факта.
- Проведено исследование причин спама. → Нашли причину спама: один домен подписи на все потоки.
- Нами было принято решение о выключении. → Выключил рассылку 14.07 сам.
- Проверка документов проводится модератором. → Модератор проверяет документы.

**Неопределённое** — «более», «около», «ряд», «некоторые», «различные», «и
т. д.», «от N ₽». Точная цифра или список; число меняется — дата среза.
- Более 20 000 клиентов. → 21 380 клиентов на 1 сентября.
- Некоторые объекты заполнены неправильно. → Пять объектов: U-195, U-106, U-194, U-243, U-200.
- Уборка от 1 500 ₽. → Студия — 1 500 ₽; двухкомнатная — 2 400 ₽.

Отдельно — **брехня**: не ложь, но расплывчато-неопровержимое («не только
ленивый», «резко повышает шансы», «многократно», «пожалуй, лучший»). Лечится
фактом, в том числе неудобным: «64 человека пришли, 1 бронь».

## 6. Синтаксис: действие, актор, одна мысль

- В предложении есть **кто** и **что сделал**.
- **Одно предложение — одна новая мысль.** Ориентир до 20 слов; больше 25 —
  делить. Знакомишь с новым и тут же ставишь его во взаимодействие — это два
  предложения.
- Причастный оборот → глагол или отдельное предложение. Скобки → убрать или
  вытащить наружу: скобки говорят «это неважно».
- Перечисление однородных — сократить до того, что нужно для решения.
- Прочитай вслух. Не хватило дыхания или сбилась интонация — сложно.

## 7. Следы нейросети в русском

- **Тире через слово** — норма не больше 4 на 100 слов.
- **Правило трёх** во всём: три прилагательных, три пункта. Пиши столько, сколько есть.
- **Отрицательный параллелизм**: «не просто X, а Y», «дело не в X, а в Y»,
  «не только…, но и» дважды на абзац.
- **Связки в начале предложения**: «Также», «Кроме того», «При этом», «Таким
  образом», «В целом». Мысли и так соседние.
- **Ровные абзацы** одной длины. Живой текст неровный.
- **Артефакты чат-бота**: «Давайте разберёмся», «Отличный вопрос», «Надеюсь,
  поможет», «Если будут вопросы — обращайтесь», «Подводя итог».
- **Мораль в финале**, **жирный** как эмфаза, **эмодзи-декор**, **заголовки**
  в сообщении на 80 слов, **выдуманные оценки сроков** («день», «пара часов»),
  которых не просили.
- **Кальки**: «делает смысл», «в конце дня», «на ежедневной основе», «имеет
  место быть», «функционал», «данный», «является».
- **Английская проза** в ответе на русский вопрос. Термины латиницей — можно.

В обратную сторону: не добавляй «живость» — частицы, шутки, образы,
восклицания, которых не было бы у автора. Слой нейросети снимается удалением,
не дописыванием. Дали образцы текста — подстройся под их ритм и лексику.

## 8. Проверка и выдача

1. Один прогон линтера: `python3 <папка скилла>/scripts/check.py черновик.txt`
   (`--source`, `--max-words N`, `--no-greeting` по ситуации). Балл ЧИСТОТА и
   попадания по категориям. Каждое попадание — решение: удалить, заменить
   фактом или оставить осознанно (термин, цитата). Поправил — отдавай; не
   гоняй до 100 и не запускай второй раз. Без python — пройди по п. 5 и п. 7.
2. Перечитай как читатель: после двух строк понятно, что случилось и что
   делать? Есть слово, которое можно убрать?
3. Отдай текст. Скилл не упоминай, «проверил по чек-листу» не пиши. Принял
   допущение — одна строка **вне** текста.
4. Просили файл — `<slug>_ru.txt` там, где принято в проекте, и покажи содержимое.

## Свой текст vs чужой

- **С нуля** — все восемь пунктов.
- **Дали черновик** («сократи», «причеши», «перепиши») — сохраняй факты, порядок
  аргументов, регистр и интонацию автора. Убираешь воду и следы нейросети, не
  переписываешь голос. Строчные буквы, «бро», мат в рабочем чате — выбор автора.
- **«Проверь», «что не так»** — не переписывай, верни находки с цитатами и заменой.
