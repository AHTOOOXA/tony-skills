# Личные правила — шаблон

Скопируй в `~/.claude/pishi/house-rules.md` и заполни. Скилл читает этот файл
перед каждой задачей; правила отсюда сильнее дефолтов из SKILL.md.

Самый полезный источник — твои собственные правки. Когда ты второй раз
исправляешь одно и то же в тексте нейросети, это правило. Записывай цитатой,
что ты сказал, и правилом, которое из этого следует: цитата держит контекст,
правило — исполнимо.

Не храни здесь ничего, что нельзя показать посторонним, если файл живёт в
публичном месте: реальные цифры, имена коллег, коды. Держи файл вне публичных
репозиториев.

---

## Длина и прелюдии

> «без привет, одним предложением, просто суть»

**Правило.** Рабочее сообщение начинается с сути. Просили одно предложение —
одно. Сообщение в мессенджер — один экран.

## Цифры

> «убирай эти цифры непонятно откуда, оставляй только наши данные»

**Правило.** Только числа из источника. Никаких «норм рынка», «обычно», «в
среднем». Источник — отчёты о сделанном, не план.

## Объяснения

> «объясни по-русски ещё раз, ничего не понял»

**Правило.** Вопрос по-русски — ответ по-русски целиком. Объяснение строится:
конкретный пример из нашей системы → механизм → последствия → что предлагаю.
Переспросили — смени пример, не повторяй формулировки.
