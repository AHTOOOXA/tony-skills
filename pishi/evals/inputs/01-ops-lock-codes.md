# Заметки разработчика — TASK-731, в кабинете гостя «Код ещё не готов» на объектах с электронным замком

Контекст (сырой, из отладки):

- Кабинет гостя (/app/<бронь>) показывает код от квартиры из поля объекта `access_code` («Код доступа» в админке). Поле `entrance_code` («Код от подъезда») — это домофон, в кабинете подписано «Код от домофона».
- Тип замка кабинет берёт из поля `access_method` («Способ заселения»): `keybox` («Ключница») или `electronic_lock» («Электронный замок»). До PR #904 кабинет считал электронным замком только объекты с интеграцией; остальные подписывал как ключницу → гость видел «Ключница» под фото замка и на выезде «оставьте ключи в ключнице». PR #904 чинит подписи, едет с ближайшим релизом.
- Причина «Код ещё не готов»: операционка положила код от квартиры в `entrance_code` вместо `access_code` на нескольких объектах. `access_code` пустой → кабинет пишет «Код ещё не готов, напишите в поддержку». `access_code` — только цифры (без букв и #).
- Название «Код доступа» = «код, которым гость попадает в квартиру», хоть на ключнице, хоть на замке.
- `entrance_code` — подъезд/домофон. Три объекта в одном доме делят один код подъезда.
- Когда хост меняет код на замке: правка `access_code` в админке показывает диалог — оставить старый код активным броням / обновить тихо / обновить и написать гостям. Диалог сделан ровно для этого.
